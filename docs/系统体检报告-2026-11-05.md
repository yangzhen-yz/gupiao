## 三、真正的优势（不是客套）

1. **有一套「不迷信自己」的制度**。影子实验台账明确写着"判据没到就保持未裁决，不许写成已上线"；已主动证伪并下线 3 个实验（只数≠3 空仓、权重引擎翻向、零样本三因子 A2）。这在自建量化系统里极其少见——多数人是把回测好看的东西直接上线。
2. **六口径可成交性拆解**。把"纸面收益"和"真实能成交的收益"分开算，是这套系统最值钱的设计，也正是它自己揭穿了纸面胜率。
3. **工程防御做得实**。东财风控特征识别（`RemoteDisconnected`）、四层限流+指数退避熔断、新浪个股流兜底、SWR 写后失效代数、SPA 静态缓存 no-cache、单飞闸门、预热串行化——这些都是踩过坑才写得出来的。
4. **性能已到"接近本地极限"**。收评分页 gzip **7886B**（原 111203B，14.1×）、`ETag` 304 零传输、60 次评分 871ms→3ms（281×）。

## 四、本轮发现并已修复的 bug

### 双源一致率为什么会从 1.1% 跳到 97.2%

**这个指标是什么**：每天 16:30，系统拿腾讯自选股（westock）当独立第三方，跟自己抓的行情/资金流逐只对账，看涨跌幅是否一致（`quote_agreed`）、主力资金流方向是否冲突（`direction_conflict`），结果落 `data_cross_check`。

**实测异常**：

| 日期 | 可比只数 | 差值中位 | 一致率 |
|---|---|---|---|
| 2026-11-04 | 146 | 0.000 | 63.0% |
| 2026-11-02 | 141 | **6.810** | 3.5% |
| 2026-10-30 | 142 | 0.000 | 97.2% |
| 2026-10-29 | 150 | **11.150** | 3.3% |

**定性**：用本地 346 万行日K反查，**westock 侧逐只准确**（11-02：中信证券 5.19、国金证券 10.03、中国船舶 2.16 全部与日K吻合），错的始终是我方。

**根因（三处叠加）**：
1. `collect_our_values()` 只读「最新一份资金流快照」，**从不校验快照是不是校验日当天的**。补跑 11-02 时等于拿 11-04 的行情去比 11-02 → 中位差 6.8 个百分点。这是主因。
2. 容差 `_QUOTE_TOL = 0.011` 实际要求"两位小数完全相等"，两源四舍五入口径不同（−0.58 vs −0.50）就判不一致 → 指标被噪声淹没。
3. 文件头注释写"本地行情走腾讯、westock 也是腾讯系，同源预期 100% 一致"——**实现取的是东财资金流快照的 changePercent，根本不是腾讯同源**，注释误导了后续判断。

**影响面（要说实话）**：`data_cross_check` 里历史几天的"资金流符号冲突 10%～26%"含大量假冲突；而"单一源资金流不可作重仓依据"这个结论方向是对的，但支撑数字打了折扣。

**已修**：
- `collect_our_values(date_key)` 认日期，不符返回空表 = **不可校验**
- 不可校验时**只落 westock 权威快照、不写比对行**（全 NULL 行会把一致率分母撑大）
- 容差 `0.011 → 0.05`（仍远小于涨跌停量级）
- 摘要新增 `our_side_usable` / `skipped_compare`
- 自测 **36 → 45 条全过**；真实数据验证：同一份快照查 11-02/11-03 判不可校验、查 11-04 正常取到 146 只

## 六、作为投研系统的判断（非工程视角）

1. **纸面 61% 胜率不可外推**。`recommendation_review` T+1 胜率 61.0%/均值 +1.82%（n=141）是**收盘买→次日某价卖**的纸面口径；换成真实可成交（竞价/收盘/开盘三种入场 × 两种出场）后，六个组合里五个为负，最好的一组 +16.96% 回撤也有 12.38%。此前复盘已明确：低吸纸面 60.4%/+1.24%，真实可成交仅 42.1%/−1.06%，**44/139 是"未成交的幻觉胜利"**。
2. **系统最该被相信的指标是"可成交净收益"，不是胜率**。当前它指向"策略还没跑通预期"，这是有价值的坏消息。
3. **数据降级期不宜据此下交易决策**。东财全域熔断 + 腾讯行情延迟 3.3s 时，资金流与热点板块都在兜底路径上跑，此时的热点判断置信度应打折。
4. **纪律层面反而是强项**：阶段闸门不跳（P1 影子 → P2 纸面 → P3 小仓）、不降门槛、跨阶段需拍板——这套流程执行住，比多赚几个点更值钱。
