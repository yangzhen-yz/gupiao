游资四派视角下的选股策略审查

审查对象：A股短线交易台（13因子日内评分 + 趋势V4.0 + 智能推荐 + 买法矩阵实测） · 对照派别：炒股养家 / A神 / 赵老哥 / 退学炒股
总体定性：防守端已达退学炒股水准；进攻端缺「周期调度、主线识别、可成交性」三个结构性部件——2026-10-18 经外部审查勘误后，「最大矛盾是可成交性而非打板连板数」

一、结论先行（TL;DR）

① 你的系统是「选美」，游资是「跟随」

13因子加权排名选前三，本质是「我认为谁好」；游资只做「市场已经用真金白银选出来的谁」。你手里有涨停时间、封单、龙虎榜、连板梯队、昨日溢价——全部原料都在，却只拿来做加分因子，没有做主选举。

② 你的 edge 全在「等低吸」，产品却在诱导追高

同一批推荐票：按低吸参考价执行 T+1 胜率 60.4%，按现价追高只剩 43.2%（本系统139条复盘，2026-10-17）。更狠的是可成交性：126 条推荐里 64 条推荐时已封死涨停、尾盘根本买不到——硬按尾盘价执行三个月 10 万变 7.5 万，按「次日竞价+高开5%不追」执行是 10.6 万。入口口径决定生死，这是全报告最该排在前面的一条（见下方勘误④）。

③ 情绪数据只用于「仓位旋钮」与「硬否决」，没用于「模式调度」

你自己的实测就是养家情绪周期的直接证据（1094口径，2026-10-17重跑）：涨停120~250家（极热）T+1 胜率 42.6% 全场最差、涨停≤50家（冰点）52.0% 最好、大跌日推荐 82%。系统响应目前只有两档：仓位三/五/七/九成 + 行动台的 cycle_gate 硬否决（不接力/不追高/提门槛分）——没有「周期位置 → 启用什么模式 → 要不要空仓」的调度输出（详见勘误③）。

一句话诊断：系统把「稀缺的重仓机会」做成了「每日3只的日常供应」——四派游资的共同做法恰恰相反：没机会时空仓，有机会时重拳。下面的每一派诊断，最终都收敛到这一个病根。

一·补 外部审查勘误与增补（2026-10-18）

本报告初稿完成后经历一轮外部逐条审查（审查者把全部量化依据对照代码与源文档核了一遍）。审查意见大部分成立，本节公示已改正的硬错误、已过期的数据、以及审查推动下补测的新维度；不认可的部分在节末单列理由。正文其余章节均已按本节口径更新。

勘误① 「打板过滤限定首板/二板」是稻草人——已删除

原文错误：称「评分奖励高连板、买入执行却限定首板/二板」是全系统最大自相矛盾。核实结论：buy_rules.classify() 的「可打板」只看当日是否封住（≥9.85%），排除项仅 20日涨幅>60%、量比>5 天量、巨量拉升——没有任何连板数限制。原文把研究文档里的「最优组合是首/二板 + 20日≤40% + 量比≤3」误当成了系统过滤器。改正后的真问题是：评分体系给 5连板+ 30分、首板 12分（trend.py:335），但高连板票没有配套的持仓期限规则——趋势池关注周期「未来~1个月」，而连板梯队 5日大面率 45.6%→74.8% 逐级抬升，高板以趋势/波段名义持仓过夜两天以上就是在接飞刀。这条比稻草人版本更值钱，已升级进路线图 P1-1。

勘误② 止损参数引错——已按「三套机制」精确化

原文错误：泛称「系统止损 = 振幅×0.8、钳制[4%,8%]」。核实结论：系统实际存在三套并存机制——(a) risk_control.py:105 振幅×1.5 钳制[4%,12%]；(b) position.py:33 按振幅分档 6/8/10/12%；(c) review.py 明日买入计划 振幅×0.8 钳制[4%,8%]（原文引的其实是这一套，但只覆盖明日买入计划，不是全系统）。推论保留一半：「止损窄于回撤噪音」只对低波动档成立（10日最大不利中位 -4.95%，4~6% 止损确实会被洗掉）；高波动档 10~12% 不成立。已按此重写 A神诊断与 P1-1。

勘误③ 两处数据过期 + 「没有模式开关」已不完全成立

  • 复盘样本 132→139 条（2026-10-17）：低吸参考价口径 T+1 胜率 60.4%/均值+1.24%，现价追高口径 43.2%/均值-1.39%——gap 仍在，但比初稿引用的 62.9%/45.5% 收窄。
  • 「没有模式开关/复盘没有模式标签」部分过期：行动台早已上线 cycle_gate 硬否决（不接力/不追高/提门槛分）、买法矩阵有日级「减仓日」、影子精选自 10-14 起按周期门槛跑对照、strategy_snapshot 已落 role/timing/matrix 三列标签。仍然成立的是：这些标签没有被聚合成榜、没有形成「周期位置→模式」的显式调度输出——缺的是最后一公里，不是从零起步。

增补⑥ 极热档：禁的是低吸追高，不是打板

3051 口径下「极热日只卖不买」的结论在 1094 口径被细化：极热档全体买入确实最差（120~250家：42.6%/-0.28%），但同一动作「封板接力」在极热档仍达 67.1%/+2.06%（样本957，亏超5%仅0.8%）。含义：极热的危险在于低吸与追高（人群拥挤、接力盘枯竭），早盘主线板反而是资金最后的共识方向。映射表已从「极热一律空仓」改为模式级禁令：禁低吸/追高、保留打板但限主线早盘板。

  • 「低吸 edge 基本不可执行」——不完全认同。审查者用尾盘口径 -25% 论证 edge 不存在，但 rec_sim 同时给出了 auction 口径 +6.48%（101/126 成交、mdd 15.83%）：纪律化执行（竞价 + 高开5%不追）是一条可成交且为正的中间路径。真正结论是「edge 只在特定入口口径下存在」，这加强而非削弱执行层改革——把默认动作从「现价/尾盘」改成「挂低吸单」，正是为了让用户落到 +6.48% 那一档而不是 -25% 那一档。

三、四派逐派诊断

炒股养家情绪周期 · 大局观 · 借势
方法论标签（公开资料普遍认知）：市场情绪是超短第一变量；情绪周期分冰点→修复→主升→高潮→退潮；「买入要借大盘与板块的势」；高手买入龙头，超级高手卖出龙头。
你已经做对的：
  • 情绪五维周期（涨停数/炸板率/连板高度/昨日溢价/涨跌家数）+ 市场温度计已经建成，数据基础比多数游资手工复盘更扎实。
  • 实测证明「极热收手」（1094口径，120~250家胜率42.6%/-0.28%）与「大跌日是机会」（82%），这正是养家「别人贪婪时我更恐惧、别人恐惧时我更贪婪」的数据版。
结构性缺口：
  • 情绪只当「仓位旋钮」和「硬否决」，没当「模式开关」。仓位随大盘三/五/七/九成是对的，行动台的 cycle_gate（不接力/不追高/提门槛分）也是对的，但养家的用法是周期位置决定做什么动作：退潮期空仓、冰点低吸试错、主升打板龙头。你的系统在所有情绪阶段输出同一种产品：3只推荐 + 同一套评分。注意 1094 口径的细化：冰点（涨停≤50）反而胜率最高 52.0%——「退潮/冰点=全面撤退」是过度简化，正确做法是切模式而非简单清仓。
  • 没有「题材生命周期」模块。预热/启动/发酵/高潮/分歧/退潮六阶段在你系统里不存在——板块动量修正只是「当日板块涨跌幅 ±5%」的环境分，回答不了「主线是什么、到哪阶段、龙头是谁、梯队完不完整」。养家会说：连主线在哪都不知道，选出来的票拿什么借势？
  • 卖出端没有周期感知。「超级高手卖出龙头」在你的系统里是固定动作（次日竞价卖），没有「高潮期一律兑现、退潮期首板都不碰」的周期化卖出规则。
A神（asking）跟随而非预测 · 重仓机会 · 错了就认
方法论标签（公开资料普遍认知）：超短最重要的是「跟随」不是「预测」；看对方向重仓出击；只做最强的票；止损坚决、不找理由。
你已经做对的：
  • 防炸板三道防线 + 死猫反弹门控，是把「错了就认」工程化得最彻底的部分——万向德农事故后的补救是全系统最有价值的补丁。
  • 打板辅策略（尾盘确认封死才买、次日开盘直接卖）本质是「一剑封喉」式短打，与1094口径实测 +2.05%/64.6% 自洽。
结构性缺口：
  • 「每日≤3只 + 行业分散」是反龙头的。行业分散是价值投资思维，用在超短上自我矛盾——超短的行业分散只会让你永远买不到主线龙头。A神一周只有一两个重仓机会；你的系统把稀缺机会做成日常供应。你实测「2026年平均每天25只打板机会」（1094口径全市场）——这个数字本身就说明该档位不够稀缺，需要周期调度来提纯，而不是来者不拒。
  • 评分是「选美」，不是「跟随」。谁先涨停、封单多厚、带动几只跟风、昨日涨停今日溢价如何——市场用真金白银投票的结果才是A神的选股输入。你的 RPS 是事后区间涨幅（天然滞后2-5天），不是当日合力排序。
  • 止损是「伪纪律」——但只有低波动档成立。系统实际有三套止损并存：单票风控 risk_control.py 振幅×1.5 钳制[4%,12%]、持仓 position.py 按振幅分档 6/8/10/12%、明日买入计划 review.py 振幅×0.8 钳制[4%,8%]。而1094口径实测：趋势票持有10日「最大不利中位 -5.36%」。精确的结论：低波动票被压在 4~6% 下限，确实窄于正常回撤噪音，会在毫发无损的正常波动中被系统性洗掉——看似严格，实则无效；但高波动档 10~12% 并不窄，问题在别处（触发即重伤）。A神的止损是逻辑证伪（买入理由不在了）+ 时间止损（买了3日不动就走），不是一个百分比。

方法论标签（公开资料普遍认知）：首板看不出龙头，二板确认后才上；大盘向好才重仓；分歧转一致时介入；高板赢的是惯性，一天都不能多留。
你已经做对的：
  • 趋势评分 D2 连板高度分层（5连板+=总龙头30分）说明你懂「板越高越强」；打板次日开盘卖符合「一天都不能多留」。
  • 可打板排除 20日涨幅>60% 过热票、量比>5 天量、巨量拉升（注意：没有连板数限制——见勘误①，这不是缺点）——风控意识在线。
结构性缺口：
  • 自家数据打架（见图3，勘误①修正版）。不是「执行限首板/二板」—— buy_rules 对连板数没有限制，数据最好的三板/四板在 1094 口径下达 68.7%/+3.81%、66.4%/+3.23% 且系统允许打。真问题是：评分给高连板加分、持仓管理却没有配套期限规则——高板以趋势名义过夜就是在接飞刀（5日大面 74.8%）。研究得出的「最优组合首/二板 + 20日≤40% + 量比≤3」也从未落地成显式模式。
  • 连板股被放进「波段」管，是错配。趋势池关注周期「未来~1个月」，但连板股 5日内大面率最高 74.8%（1094口径）——高板必须归「打板模式次日走」，一旦以趋势名义持仓过夜两天以上，就是在接飞刀。你记录了 45.6%→74.8% 这组数字，却没用在持仓期限规则上。
  • 没有「分歧转一致」的买点时点。为可成交性选「尾盘确认封死」，等于系统性买入最弱的一类板（跟风板/中军板）。缺一张「封板时间（早/午/尾）× 题材地位（主线龙头/分支/跟风）」的收益拆解表——这是数据缺口，先补数据再谈放宽，不能凭信仰放开。
  • 择时只有仓位版，没有开关版。赵老哥退潮期空仓；你的系统退潮期照样推3只。「大跌日胜率82%」被用来否决弱市门控是对的，但那说明弱市该出的是稀有的冰点低吸（防守型机会），不是照常供应。
退学炒股慢就是快 · 回撤控制 · 空仓 · 复盘闭环
方法论标签（公开资料普遍认知）：回撤是复利的第一杀手；空仓是高级别的操作；每种模式做到极致；不随手单、知行合一。
你已经做对的——四派里你最像他：
  • 买法矩阵实测（1094口径45.9万条样本）、推荐复盘139条、30天亏损黑名单、盈亏比≥1.5强制——这套东西就是「把模式量化」的退学炒股式工程，多数手工游资做不到这个颗粒度。
  • 低吸为主 + 打板为辅 + 接力/波段不做的收敛结论，本身就是「将模式做到极致」的正确方向。
结构性缺口：
  • 知行合一（全报告最严重的一条，含可成交性）。系统 edge 全在低吸参考价（139条复盘：60.4%），现价追高只剩 43.2%；明日买入计划已经有挂单价（buyLow~High），但执行层没有强制「不到价不买」。更狠的是可成交性（见图4）：126条推荐中64条推荐时已封死，尾盘价硬吃三个月 -25%，只有「次日竞价+高开5%不追」这一种纪律化入口同时满足可成交与正期望（+6.48%）。退学炒股的原话逻辑：不能实盘的纪律等于没有纪律。你的前端把「现价买入」放在手边，就是在训练用户随手单。
  • 复盘按日期，不按模式。每笔推荐应带模式标签（低吸/打板/冰点反弹/主线加速），按模式统计 T+1/T+5 才能回答「哪种模式值得加码、哪种该停」。好消息：strategy_snapshot 已有 role/timing/matrix 三列标签、影子精选自10-14起按周期门槛跑对照——缺的是聚合成榜与持续反馈，不是从零起步。
  • 没有账户级回撤熔断。单票止损管不了「连续小亏的累积」：低吸约 40% 的不胜率 × 平均 -2%，连来5次就是 -10%。缺「月回撤>X% 总仓减半、连亏3笔停打板3日」的节奏层——这就是「慢」的机制。
  • 「空仓」不是正式输出。退学炒股一年重仓几次；你的系统每天都推。机会明明不均匀（大跌日82% vs 极热日42.6%）——「今日无机会」应该成为推荐系统的一个正式状态，而不是空白。

P0-1可成交性优先：执行诚实化 + 入口口径监控
问题：全部 edge 死在「买不到、买贵了」。126条推荐64条推荐时已封死；尾盘口径三个月 -24.99%，竞价纪律口径 +6.48%，排板全成交幻想 +24.53%——同一批票，入口口径差 70 个百分点。

P0-2上线「情绪周期 → 交易模式」调度层（1094口径校准）
问题：情绪数据只驱动仓位与硬否决，不驱动模式；所有情绪阶段输出同一种产品。
改动：每日盘前用情绪五维 + 连板梯队完整度判定周期位置，按映射表切换模式（见下表，阈值已按 1094 口径重跑校准）。调度层输出「今日模式」到收评/推荐页顶部；「空仓」成为正式输出状态（推荐区显示空仓理由，而不是硬凑3只）。上线闸门：与影子精选并行开发，影子数据≥10个交易日后才切线上。
预期收益：避开极热低吸/追高（42.6%/-0.28%）、主打冰点（52.0%/+0.20%）与正常期双模式（打板+2.05%/64.6% + 低吸+1.32%/66.3%），仅此一项即可把整体期望从「每日均匀供应」改为「不均匀但正向加权」。
风险：周期判定的阈值需持续用新数据回归校准，避免把映射表做成新的硬编码信仰；注意冰点反而是胜率最高档——切模式不等于简单清仓。

P1-1止损重构：统一三套机制 + 连板期限规则
问题：三套止损并存（risk_control 振幅×1.5钳[4,12] / position 分档6/8/10/12 / review 明日计划 振幅×0.8钳[4,8]），用户看到的口径不统一；低波档 4~6% 窄于趋势票正常回撤噪音（10日最大不利中位 -5.36%），会被系统性洗掉。

预期收益：止损从「被噪音触发」变为「被证伪触发」，减少无谓磨损；连板股纳入次日兑现，规避尾部。

P1-2打板分层验证：把研究出的最优组合落地成模式
问题（勘误①修正版）：buy_rules 对连板数没有限制（原「限首板/二板」是稻草人），但两个真问题还在：研究得出的「最优组合首/二板 + 20日≤40% + 量比≤3」从未落地成显式模式；高连板数据最好（三板 68.7%/+3.81%）却缺可成交性保障（竞价≤+2% 能买到仅 39.4%）与封板时间×题材地位拆解。

P2-2模式标签聚合成榜：让「每种模式做到极致」可度量
问题：139条复盘按日期统计，模式优劣不可比；strategy_snapshot 的 role/timing/matrix 标签还没有被消费。

六、反向声音：哪些「问题」其实不是问题

  • 基本面因子不是超短的累赘。13因子里的 ROE/净利同比看似与打板无关，但它作为「防炸板、防垃圾股」的防护网有实证支撑——涨停股次日反转惩罚（9.1.2）正是靠这类信号提前降险。养家的大局观本来就包含基本面这一维。
  • 「大跌日推荐胜率82%」说明你的系统已经在用数据对抗直觉。四派游资靠盘感动辄栽在弱市一刀切上，而你用139条复盘否决了弱市门控——这是手工游资做不到的事，保留它。
  • 极热日「一刀切禁打板」不成立（1094口径新增）。极热档全体买入确实最差（42.6%/-0.28%），但封板接力在极热仍 67.1%/+2.06%（957样本、亏超5%仅0.8%）。同类反直觉数据还有：炸板率>50% 的极端分歧日 T+1 胜率 58.9%/+0.67%（8,625样本）——情绪指标的正确用法是切模式，不是拉闸刀。
  • 每日3只在资金量小、靠复利累积的阶段是合理的。问题不在数量，在于模式不分层：退潮日的3只和主升日的3只不应该是同一个3只。调度层（P0-2）正是为解决这个而设，而不是简单削减供应。
  • 行业中性化（±2）在选美体系里是对的补充。它防的是「热门行业集体虚高」，在调度层上线前，它是系统唯一在用的「防拥挤」机制，先别拆。
全报告最大的风险提示：本报告全部量化依据来自你自己的回测（1094口径，2025-01 ~ 2026-10）。该样本内打板期望已从 +2.02%（2025）收窄到 +1.51%（2026）——所有模式都在变窄。路线图上线后必须持续用新数据回归验证，尤其防止「周期→模式映射表」被当成新的信仰固化。游资方法论的引用为公开资料中的普遍认知（非一手来源），如涉及具体语录细节需核实原文。
