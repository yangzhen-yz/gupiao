                from services.recommend import fetch_batch_fund_flow

            except Exception as e:
                print(f'[批量扫描] 资金流向获取失败: {e}')

## 假设与决策

1. **holder_map 获取方式**：DB 查询用 `asyncio.to_thread` 包装，遵循 project_memory 硬约束"requests 同步客户端用 asyncio.to_thread 包装"。DB 查询虽是本地 IO，但仍可能阻塞事件循环（5000 股票批量查），故包装。
2. **import 位置**：routes.py 和 trend.py 使用局部 import（参考现有 fund_flow 的局部 import 模式 L725/L1482），避免顶部 import 污染和循环导入风险。recommend.py 也用局部 import 保持一致。
3. **单股端点不用 to_thread**：`/api/stock/{symbol}/analysis` 只查 1 只股票，DB 查询极快，直接同步调用 `get_holder_num_batch([sym])`，无需 to_thread 开销。
4. **holder_data=None 降级安全**：`_score_holder_structure(None, None)` 返回 `vals['no_data']=8`（中档分），DB 无数据时不拖累总分。这已由 strategy.py L50-52 处理。
5. **不修改 factor_values**：L337 的 `holder_structure` 键已存在，无需改动。
