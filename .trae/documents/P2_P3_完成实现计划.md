### 1.1 定义 3 个新函数（在 `_calc_sector_factor` 之后，约 line 881 之后插入）

**`_classify_market_regime(market_change: float, index_kline: Optional[List[List]]) -> str`**
- 用途：P3-1 大盘状态分类，返回 `'bull'`/`'bear'`/`'range'`
- 逻辑：
  - 若 `index_kline` 为空或长度 < 20 → 直接用 `market_change`：≥`TREND_DYNAMIC_MARKET_BULL_CHANGE`(0.5)→bull，≤`TREND_DYNAMIC_MARKET_BEAR_CHANGE`(-0.5)→bear，否则 range
  - 否则计算大盘 MA20（复用 `calculate_ma`），取最新收盘价 vs MA20：
    - `index_close > ma20` 且 `market_change >= 0.5` → `bull`
    - `index_close < ma20` 且 `market_change <= -0.5` → `bear`
    - 其他 → `range`
- 容错：任何异常返回 `'range'`（最安全默认，dyn_thresh 走全局默认）

**`_get_dynamic_thresholds(market_regime: str, pattern: str) -> Dict`**
- 用途：三级优先合并动态阈值 → 返回含 6 个 key 的 dict（`D1_DIVERGENCE_PENALTY_TIERS`/`DEDUCT_VOLUME_SPIKE`/`DEDUCT_MA20_BROKEN`/`D4_DRAWDOWN_TIERS`/`DEDUCT_VOLUME_DIVERGENCE`/`DEDUCT_AMPLITUDE_FLAT`）
- 逻辑：
  1. 以 `dict(TREND_DYNAMIC_DEFAULTS)` 为基底（拷贝）
  2. 查 `TREND_DYNAMIC_THRESHOLDS.get((market_regime, pattern))`，命中则 `.update()` 覆盖
  3. 返回合并后的 dict
- 这保证 6 个 key 一定存在，line 156 + 6 处 dyn_thresh 引用不会 KeyError

**`_calc_chip_factor(check_price, ma60_val, ma120_val, turnover_rate, main_inflow_ratio, cv) -> float`**
- 用途：P2-1 筹码结构修正系数（代理指标方案）
- 4 子项相加后钳制到 `[TREND_CHIP_FACTOR_MIN, TREND_CHIP_FACTOR_MAX]`：
  1. 成本压力位：现价 vs MA60/MA120（都 None→0；都上方→`TREND_CHIP_COST_ABOVE_BOTH`；都下方→`TREND_CHIP_COST_BELOW_BOTH`；之间→`TREND_CHIP_COST_BETWEEN`）
  2. 换手率筹码松动度：1-3%→`LOCKED`；>15%→`LOOSE`；其他→`NORMAL`
  3. 主力筹码动向：`main_inflow_ratio` None→`NEUTRAL`；≥3→`ACCUMULATE`；≤-3→`DISTRIBUTE`；之间→`NEUTRAL`
  4. 量能稳定性 CV：`cv` None→`NORMAL`；≤0.3→`STABLE`；>0.8→`VOLATILE`；之间→`NORMAL`
- 返回 `max(MIN, min(MAX, sub1+sub2+sub3+sub4))`

## 阶段 2：P3-2 行业中性化（三层对齐）

### 设计决策
行业中性化作为**共享后处理 helper**（`apply_industry_neutralization`），在三条评分路径计算完 `calc_stock_score_v2` 基础分后统一调用。**不修改 `calc_stock_score_v2` 签名**，逻辑收敛在单一函数，三层对齐 = 三处调用同一 helper。

中性化对象：`calc_stock_score_v2` 输出的 `score['total']`（日内策略分）。trend.py 的 `trend_score` 已有 `sector_factor`(P0-1) 做环境修正，不再叠加行业中性化，避免双重修正。

### 2.1 config.py 新增（在 P3-1 配置块之后）
```python
# ========== P3-2 行业中性化（2026-06-30）==========
STRATEGY_INDUSTRY_NEUTRALIZATION_ENABLED = True
STRATEGY_INDUSTRY_NEUTRAL_MIN_SAMPLE = 5   # 单行业样本<5 不做中性化（统计无意义）
STRATEGY_INDUSTRY_P80_BONUS = 2            # 行业内总分 ≥ P80 → +2
STRATEGY_INDUSTRY_P20_PENALTY = -2         # 行业内总分 ≤ P20 → -2
```

### 2.2 strategy.py 新增 helper
在 `calc_stock_score_v2` 之后新增：
```python
def apply_industry_neutralization(stocks: List[Dict], industry_map: Dict[str, str]) -> None:
    """P3-2 行业中性化：按行业分位数调整 strategy_score.total（原地修改）

    Args:
        stocks: 待评分股票列表，每个元素须含 stock['score']['total'] 和 stock['symbol']
        industry_map: {symbol_lower: industry_name}，来自 fetch_batch_fund_flow 的 f100
    原则：单行业样本<MIN_SAMPLE 跳过；≥P80 +2，≤P20 -2，中间不动；记录 industryAdjust
    """
```
- 按 industry 分组收集 `(symbol, total)`
- 每组样本 ≥ `STRATEGY_INDUSTRY_NEUTRAL_MIN_SAMPLE` 才计算 p20/p80（用排序索引近似分位数）
- 原地写回 `stock['score']['total'] = max(0, min(100, total + adj))`，并 `stock['score']['industryAdjust'] = adj`
- industry 为空字符串归入 `'其他'`
